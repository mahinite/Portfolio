# Portfolio

My personal portfolio: who I am, my life so far, the things I build, and where I'm headed. It's meant to be a living record I can look back on, so it's built to be easy to update.

## What's inside

- **About me**: the story, the lore, the goals
- **Projects**: things I've built.
- **Interactive touches**: animated backgrounds, hover effects and smooth page transitions

## Tech stack

- [React 19](https://react.dev) with [TypeScript](https://www.typescriptlang.org)
- [Vite](https://vite.dev) for dev server and builds
- [Tailwind CSS v4](https://tailwindcss.com)
- [Motion](https://motion.dev) for animation, [OGL](https://github.com/oframe/ogl) for WebGL effects
- [Lucide](https://lucide.dev) icons
- [Bun](https://bun.sh) as the package manager (see `bun.lock`)


## Project structure

```
├── src/          # app source (components, pages, styles)
├── lib/          # shared helpers
├── public/       # static assets
├── index.html    # entry HTML
└── vite.config.ts
```
